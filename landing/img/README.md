# Fotos de la landing

Fotos reales del café, exportadas para web (sin metadatos EXIF). Para cambiar o agregar fotos,
edita el bloque `CONFIG` al final de `../index.html`.

| Archivo | Uso |
|---|---|
| `fachada.jpg` | Fondo principal (el café por fuera), 2000 px de ancho |
| `gatos/*.jpg` | Carrusel de fotos, 1400 px de alto |
| `logo.svg` | Logo oficial (copia de `../../Logo.svg`): marca del header y del footer |
| `favicon.svg` | Favicon (copia de `../../Favicon.svg`): gato sin fondo, rosa en tema claro y blanco en oscuro vía `prefers-color-scheme` |
| `apple-touch-icon.png` | `logo.svg` (con el fondo rosa) rasterizado a 180 px, para el ícono de iOS al agregar a inicio |

Los originales están fuera del repo (carpeta `client-images/`, no versionada).
